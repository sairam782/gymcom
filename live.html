Claude plan

How to use the Claude API key securely and efficiently

Claude should not be your millisecond-by-millisecond tracker. Instead, use live browser pose estimation for speed, then hand the tracked metrics or saved clip to Claude for richer narrative feedback.

Live step 1 Run MediaPipe Pose locally

Use a browser pose model for constant landmark and 3D keypoint updates, then compute depth, symmetry, and joint range from those landmarks.

Live step 2 Count reps from angle thresholds

For each selected exercise, define a top angle, bottom angle, and phase rules. That is how reps and live form score appear in real time.

Claude step 3 Generate a written coaching report

Send only the clip, sampled frames, or movement metrics the user chooses through the backend so Claude can produce a cleaner final report with less guessing.

Recommended architecture
  • Frontend live page: accessible, high-contrast interface with exercise selector and guidance cards.
  • Browser computer vision: MediaPipe Pose GHUM for full-body landmarks, kinematic analysis, and instant corrective cues.
  • Exercise rules: angle targets, rep-state machine, and left/right symmetry checks.
  • Backend save: store rep counts, angle history, sampled frames, and session metadata.
  • Claude API: turn raw movement data into natural-language reports and automated performance digests.
